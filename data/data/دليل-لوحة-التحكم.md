## تعديل الأسعار والعروض والتليفونات من موبايلك

# هيكل الملفات على GitHub

```
index.html            ← الصفحة الرئيسية
offers.json           ← العروض اليومية
data/
   ├── phones.json    ← التليفونات وأسعارها
   └── repairs.json   ← أسعار التصليح
admin/
   ├── index.html     ← صفحة الدخول
   └── config.yml     ← إعدادات اللوحة
assets/phones/        ← صور التليفونات (بيتعمل لوحده)
```

⚠️ **المجلدات مهمة.** `data` و `admin` لازم يكونوا مجلدات فعلاً، مش أسماء ملفات.

# التركيب — مرة واحدة (10 دقايق)

## ١. ارفع الملفات على GitHub

ارفع كل الملفات بنفس الترتيب اللي فوق.

**في GitHub، عشان تعمل ملف جوه مجلد:** دوس **Add file → Create new file**، وفي خانة الاسم اكتب `data/phones.json` — الشرطة المائلة بتعمل المجلد تلقائياً.

## ٢. فعّل Identity في Netlify

Netlify → الموقع → **Site configuration** → **Identity** → **Enable Identity**

## ٣. اقفل التسجيل ⚠️ مهم جداً

نفس الصفحة → **Registration** → غيّرها لـ **Invite only**

⚠️ **لو سبتها Open، أي حد على النت يقدر يسجل ويغيّر أسعارك.**

## ٤. فعّل Git Gateway

نفس الصفحة → انزل لـ **Services** → **Enable Git Gateway**

## ٥. اعمل حسابك

تبويب **Identity** → **Invite users** → إيميلك → هيوصلك إيميل → **Accept the invite** → حط باسورد قوي

# الاستخدام اليومي

**افتح:** `megawirelessusa.com/admin`
**سجّل دخول** بإيميلك وباسوردك

هتلاقي **3 أقسام** على الشمال:

## 📱 Phones For Sale
- **تغيير سعر:** دوس على التليفون → غيّر الرقم في خانة Price → **Publish**
- **إخفاء تليفون خلص:** حوّل **Show on website?** لـ OFF (مش تمسحه — لما يرجع تشغّله تاني)
- **إضافة تليفون جديد:** دوس **Add Phone** تحت القايمة
- **إضافة صورة:** خانة **Photo** → اختار من موبايلك → بترفع لوحدها

## 🔧 Repair Prices
جدولين: **أسعار الشاشات** و **الخدمات التانية**.
غيّر أي سعر → Publish. الموقع بيتحدث خلال دقايق.

## 🔥 Daily Offers
شغّل/اقفل العروض. **العرض بيظهر بشرطين:** المفتاح ON + التاريخ لسه ما عداش.

**بعد أي تعديل: دوس Publish فوق.** التغيير بيوصل الموقع خلال 1-3 دقايق.

# صور التليفونات

## إزاي تصوّر صح
- **خلفية بيضا** (ورقة A4 كفاية)
- إضاءة كويسة، من غير ظل
- التليفون في النص، مساحة فاضية حواليه
- **نفس الزاوية لكل التليفونات** — ده اللي بيخلي القسم يبان محترف

## الرفع
من لوحة التحكم → التليفون → **Photo** → اختار الصورة. بترفع لوحدها في `assets/phones`.

⚠️ **لو مفيش صورة، بيظهر الشكل الافتراضي.** مش هيبوّظ التصميم — بس الصور الحقيقية بتفرق كتير في الثقة.

⚠️ **الصور الكبيرة بتبطّئ الموقع.** خلي كل صورة أقل من 300KB. أي تطبيق ضغط صور على الموبايل بيعمل ده في ثانية.

# الألوان الجديدة

الموقع بقى بهوية مبهجة: **نيلي غامق + سماوي نيون + بمبي + بنفسجي + دهبي**

- الشريط العلوي بيتحرك بألوان قوس قزح
- العنوان الرئيسي بتدرج (دهبي → بمبي → سماوي)
- الكروت بتلمع وترتفع لما تعدي عليها
- الأزرار بظل ملون

⚠️ **ملاحظة صادقة:** الألوان المبهجة بتخطف العين، بس **بتقلل الإحساس بالفخامة**. لو حسيت إنها زيادة، قولي وأخففها درجة.

# مشاكل شائعة

| المشكلة | الحل |
|---------|------|
| Login failed | Identity أو Git Gateway مش مفعّلين |
| مفيش أقسام بعد الدخول | `admin/config.yml` مش مرفوع صح |
| عدّلت ومفيش تغيير | استنى 3 دقايق، وبعدها شوف Netlify → Deploys |
| التليفونات مش ظاهرة | `data/phones.json` مش في مجلد `data` |
| الأسعار مش ظاهرة | `data/repairs.json` مش مرفوع |

⚠️ **الأمان:** متشاركش الباسورد. لو مراتك محتاجة تعدل، اعملها **invite بحسابها هي**.
