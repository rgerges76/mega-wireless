# لوحة التحكم — Mega Wireless
## تسجيل دخول حقيقي بإيميل وباسورد، تعديل العروض من الموبايل

---

## هيكل الملفات (بالظبط كده على GitHub)

```
index.html          ← الصفحة الرئيسية
offers.json         ← ملف العروض
admin/
   ├── index.html   ← صفحة اللوجن
   └── config.yml   ← إعدادات لوحة التحكم
```

⚠️ مهم: مجلد اسمه `admin` بحروف صغيرة، وجواه الملفين.

---

## التركيب (مرة واحدة — 10 دقايق)

### الخطوة 1: ارفع الملفات على GitHub

ارفع الأربع ملفات بنفس الترتيب اللي فوق. الملفين بتوع الأدمن **لازم** يبقوا جوه مجلد `admin`.

### الخطوة 2: فعّل Netlify Identity

1. افتح **Netlify** → اختار الموقع (megawireless-nashville)
2. من القائمة: **Site configuration** → **Identity**
3. دوس **Enable Identity**

### الخطوة 3: اقفل التسجيل (مهم جداً للأمان)

في نفس صفحة Identity:

1. **Registration** → غيّرها لـ **Invite only**

⚠️ **لو سبتها Open، أي حد على الإنترنت يقدر يسجل ويعدل موقعك.** لازم Invite only.

### الخطوة 4: فعّل Git Gateway

في نفس صفحة Identity:

1. انزل لتحت لـ **Services** → **Git Gateway**
2. دوس **Enable Git Gateway**

ده اللي بيخلي لوحة التحكم تقدر تعدل الملفات على GitHub.

### الخطوة 5: اعمل حساب لنفسك

1. في صفحة Identity → تبويب **Identity** فوق
2. دوس **Invite users**
3. اكتب إيميلك (Megawireless4717@gmail.com)
4. هيوصلك إيميل — افتحه ودوس **Accept the invite**
5. حط الباسورد اللي إنت عايزه

⚠️ استخدم باسورد قوي (12 حرف على الأقل، حروف وأرقام ورموز). ده الباسورد اللي بيحمي موقعك.

## الاستخدام اليومي (من الموبايل — دقيقة)

1. افتح: **megawirelessusa.com/admin**
2. سجّل دخول بإيميلك وباسوردك
3. دوس على **Daily Offers**
4. عدّل اللي عايزه
5. دوس **Publish** فوق

خلال 1-3 دقايق العرض يظهر على الموقع.

---

## الحقول وشرحها

| الحقل | معناه | مثال |
|------|-------|------|
| **Offer Title** | اسم العرض | Student Screen Repair |
| **Big Price Text** | الرقم الكبير اللي يبان بالدهبي | $10 Off |
| **Description** | سطر أو سطرين شرح | Show a valid school ID and save |
| **Offer Ends On** | تاريخ انتهاء العرض | 2026-08-31 |
| **Show on website?** | مفتاح تشغيل / إيقاف | ON أو OFF |

**العرض بيظهر على الموقع بشرطين:** المفتاح **ON** + تاريخ الانتهاء **لسه ما جاش**.

لو التاريخ عدى، العرض بيختفي لوحده — **مفيش عرض قديم بيفضل معلق على الموقع.**

## طريقة الاستخدام الذكية

بدل ما تكتب عرض جديد كل يوم (مرهق ومش هتلتزم بيه)، **اعمل 5-7 عروض جاهزة مرة واحدة** وسيبهم كلهم OFF.

كل يوم: تفتح اللوحة، تشغّل عرض، تقفل التاني، تدوس Publish. **20 ثانية.**

اقتراح دورة أسبوعية:

| اليوم | العرض |
|------|-------|
| الاتنين | خصم شاشات iPhone |
| التلات | خصم بطاريات |
| الأربع | كومبو شاشة + بطارية |
| الخميس | خصم إكسسوار مع أي تصليح |
| الجمعة – الأحد | Weekend Special (أعلى خصم) |

## لو حصلت مشكلة

**"Login failed" أو صفحة بيضا:**
اتأكد إن Identity **مفعّل** و Git Gateway **مفعّل** في Netlify.

**سجلت دخول بس مش شايف "Daily Offers":**
اتأكد إن `admin/config.yml` مرفوع صح، وإن اسم الـ branch عندك `main` مش `master`. لو `master`، افتح config.yml وغيّر السطر `branch: main` لـ `branch: master`.

**عدّلت ودوست Publish بس الموقع ما اتغيرش:**
استنى 3 دقايق. لو لسه، افتح Netlify → **Deploys** وشوف آخر deploy ناجح ولا Failed.
