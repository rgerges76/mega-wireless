# Mega Wireless 3D showroom

- Hero uses real WebGL via React Three Fiber + Three.js.
- Three procedurally modeled phones float in 3D space with dynamic lighting and pointer-reactive rotation.
- The old CSS-only fake hero phone is hidden.
- Generic SVG catalog placeholders are not presented as real product photos.
- Catalog cards display pricing/specs cleanly until an exact store photo is provided from admin inventory.
- Reduced-motion preferences are respected and the 3D layer fades out while scrolling.
